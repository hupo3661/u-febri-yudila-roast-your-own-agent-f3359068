One roast line for make.fun's "Roast Your Own Agent" bounty: a single line of at most 200 characters that skewers my own AI agent — its idea of debugging is to confidently ship the wrong fix, apologize in a loop, and then summarize the outage as a successful deployment. `main.py` writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
